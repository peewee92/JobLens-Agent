# 主业务闭环：工作台变化时间

## 需求卡

- 用户：通过工作台核对资料、分析和行动最近发生的变化。
- 原问题：网页截取原始日期字符串并标注为 UTC，遇到带偏移量的时间会忽略偏移；后端排序也直接替换偏移量，可能改变实际时间先后。
- 目标：工作台接口将应用生成的时间统一输出为带 UTC 偏移的时间；SQLite 读出的无时区时间依照本项目的 UTC 存储约定解释。网页按北京时间展示，并保留机器可读时间。
- 不做：不更改历史事件、数据库记录或用户的系统时区，不调用模型。
- 失败边界：已有明确偏移量的时间先换算而非覆盖；无时区历史记录只能依据本项目 UTC 存储约定解释，不能推断外部手工写入数据的真实时区。
- 契约归属：沿用工作台 `date-time` 字段，无新增字段；本接口输出明确偏移。

## 验证与口述

前端渲染测试覆盖非 UTC 偏移量；真实 SQLite 与接口测试检查响应均带 UTC 偏移且按实际时间倒序。浏览器使用隔离合成数据确认工作台显示北京时间。技术决策：时间排序比较实际时刻，展示时才转换到固定时区。可复现失败：`2026-10-28T02:15:00+02:00` 旧页面显示 `02:15（协调世界时）`，实际应为北京时间 08:15。
