# 资料核对后返回原岗位范围

## 需求卡

- 用户：从岗位核对进入职业资料，补充或确认真实事实的人。
- 原行为：职业资料页没有回到原岗位及分析范围的入口。
- 目标：保留所选岗位和当前岗位，资料页提供返回岗位、返回分析两个明确入口；保存资料不会自动重算，也不会掩盖旧报告过期。
- 不做：不自动保存草稿、不自动启动匹配或模型调用；不把导航参数当作运行状态。
- 失败边界：仅接受范围内的单个当前岗位和合法范围，不接受任意返回地址；资料服务不可用时仍提供返回入口。

## 技术决策和复现

保留显式返回，而非在保存职业资料后自动跳转：用户可能还需要修改求职偏好。隔离数据复现：从两个所选岗位中的一个进入资料页，修改并确认合成资料，返回原岗位，再返回分析，原范围保留且重新检查显示资料版本变化。

## 面试口述

“资料确认与匹配更新是两个动作。我保留用户的岗位上下文，但不在保存后偷偷重新计算，返回时用新事实重新检查已有报告。”
