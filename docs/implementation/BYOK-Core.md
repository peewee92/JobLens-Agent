# 自带模型：首版需求卡

目标：快速体验保持零模型请求；真实模式按会话使用用户密钥，完成文字背景与岗位分析。

约束：独立工作目录，原分支未提交改动不变。无账户，无上传，无自然语言 Agent，无开发者密钥兜底。

接口归属：共享契约 packages/contracts；公开入口和会话权限由后端负责，网页不能自行授权。

架构决定：模型配置使用请求上下文，不改全局 Settings；已有岗位提取/匹配调用记录继续复用。

调用边界：每个授权计划一次请求；超时标记未知，不自动重试。用户账户计费，价格未知不能记零。

验收：双访客资料/连接/调用隔离，样本零调用，配置切换计划失效，密钥不落盘和不回显；内网/跳转/解析变化拒绝；重复提交不重复发请求。

上线：JOBLENS_BYOK_ENABLED 默认关闭；收费验证、推送和部署分别确认。不得把本地模拟验证写成线上验证。

面试口述：这次不是增加一个全局 API Key 设置，而是把一次付费分析的权限、资料、连接版本与结果绑定到同一个临时会话。
