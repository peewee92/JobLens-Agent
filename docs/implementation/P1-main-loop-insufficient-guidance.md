# 证据不足时的岗位核对指引

## 本次切片

当保存的岗位匹配报告结论为“证据不足”时，岗位详情展示报告中尚未匹配的具体要求和报告给出的原因，提示用户核实真实经历或学习准备；若报告没有可展示的要求，明确说明，避免凭空生成方向。资料入口保留当前岗位范围，方便补充资料后返回重新检查。

这里展示的是已有报告，不重新计算匹配，也不把缺少证据解释为不会或已经满足；完成学习行动不会自动生成职业事实。本切片不改变推荐算法、历史报告或用户资料。

## 验证

- 前端类型检查通过；前端测试 271 项通过，包括新增的已有要求展示及无要求时不编造两项测试。
- 隔离数据库和本地浏览器验证：证据不足的岗位显示待核实要求及资料入口；进入资料页后返回原分析，原岗位仍被选中。
- 浏览器使用人工改造的合成报告：其保存结论与实时资格判断可能不一致。这只验证展示和导航，不证明匹配算法真实生成该结论，也不代表证据不足的完整用户闭环已经验收。
- 未调用付费模型，未修改真实求职记录。

## 后续

仍需用由实际匹配流程生成的证据不足结果，验证补充并确认事实、重新分析、比较新旧结果的完整路径，以及故障恢复场景。
