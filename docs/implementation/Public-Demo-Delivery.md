# 公开演示交付需求卡

2026-11-02。未检测到已安装且初始化的 OpenSpec，采用轻量需求卡，不伪造工具产物。

目标：陌生访客在独立临时合成库中比较三个岗位、确认目标并开始行动；不得读取真实库、跨会话状态或调用在线模型。

契约：新增 `/api/v1/demo/session` 的 POST（创建）、GET（状态）、DELETE（重置并返回新会话）。令牌只由网页服务端保存为安全 Cookie 并转发；公开后端使用代理凭证。业务契约不变。默认闲置 30 分钟、最长两小时、容量 20；会话或进程结束后明确重新开始。

技术决定：数据库由请求上下文选择，仓储和恢复共用该上下文；不改变全局连接，不引入 PostgreSQL 或用户系统。独立部署入口强制禁用在线模型与上传，缺密钥拒绝启动。

失败例证：单用户后端直接公网部署会令访客共享资料和运行；测试必须验证交叉标识不可读、并行上下文隔离。SQLite 临时磁盘不能用于承诺跨服务重启保存。

验收：双会话完整核心流程、禁止路由、来源验证、容量/限速/过期、重置、网络禁用、现有本地回归；网页测试、类型和生产构建。部署与真实用户/真实模型证据单独记录。

面试口述：公开的是受限合成体验而不是生产多用户系统；复用实际业务路径，每位访客的数据库独立，过期明确告知，模型能力另外通过真实样本评估证明。
