# 主业务闭环阶段 2A：证据缺失不等于资格不满足

## 需求卡（2026-10-25）

- 目标用户：已确认职业资料，准备判断一批岗位的求职者。
- 原行为：缺少技能、教育或专项年限证据就被确定性资格门禁淘汰；所有待核实岗位又无条件被推荐为挑战岗位。
- 目标行为：未知进入待核实；只有已确认总工作年限低于明确硬要求才产生目前支持的硬冲突。待核实且没有核心证据支持的岗位归为证据不足，不自动成为积极建议。
- 契约负责人：后端应用层维护判断语义，`packages/contracts` 维护报告形状，网页消费相同结果。
- 不做：本轮不实现偏好硬约束、完整四组推荐展示、运行存储迁移、工作台、自动重新匹配或收费模型验收。
- 拆分：2A 资格语义与报告版本隔离；2B 结构化求职偏好；2C 推荐展示和历史消费入口统一。
- 工具：OpenSpec 未安装且仓库未初始化，使用本需求卡，不安装工具。

## 验收与失败边界

1. 缺少必需技能、学历、专项年限证据均为 `conditional`，不伪造支持证据。
2. 有本科经历不代表用户最高学历就是本科；硕士要求缺少证明仍待核实。
3. 已确认总年限低于硬要求仍为 `blocked`，附 `yearsOfExperience` 事实引用；未知总年限不阻断。
4. 待核实且无核心支持证据为 `low`；有核心直接或部分支持可为 `stretch`。
5. 新报告保存 `policyVersion=match-policy-v2`；旧快照缺字段按 v1 加载，保留原结论，不能进入当前批次排序。不是数据库迁移，也不改写历史。
6. 通过资格门禁不等于生成完整匹配；如后续语义匹配未配置或未授权，保留明确失败，绝不编造新报告。
7. 先运行规则、存储、排序和接口测试，再用只读真实数据核对规则变化；模型零调用，不改真实记录。

## 技术决策

保持既有三个资格状态，不把证据判断扩展成另一套状态机。`missing` 在 v2 中收窄为事实支持的不满足；`conditional` 表示不能判定满足或不满足。语义 `not_matched` 仍只说明当前证据不能支持要求，不代表用户不会该技能。规则版本与模型／提示词版本分离，以快照字段兼容旧库。

## 可复现失败

旧规则：资料中只有 React/RAG，没有 Java 或后端专项年限时，必需 Java＋5 年后端经验被直接判为 blocked。对应资格回归测试将其改为 conditional，并确认 evidence_ids 为空；另保留真实总年限不足的 blocked 对照。

## 面试口述

“我没有直接关闭资格门禁，而是区分缺少证明和事实冲突。一个人没有填学历不代表学历不合格；另一方面，总工作年限已经确认不足就不能让模型升级推荐。规则变化单独版本化，旧报告继续可查，但不混入新排序。放行未知也不代表积极推荐，没有核心证据的岗位仍归证据不足。”

## 本轮验证

已实现并在本轮验证：

- 资格、报告策略、真实 SQLite 快照与排序首轮定向测试：50 项通过。
- 后端全量：1433 项通过。首轮发现一条检索测试仍断言“缺少 MCP 证明就 missing”，已改为 conditional，并保持证据为空断言；未改变检索候选规则。
- 网页测试：174 项通过；类型检查、生产构建与 `git diff --check` 通过。页面文案断言同步为“明确不满足”。
- 只读真实数据核对：20 个岗位历史最新结论均为 blocked，新规则均为 conditional。**不是 20 个成功匹配或推荐**；不包含新的模型质量验收。
- 浏览器在新建隔离副本上打开真实岗位：待核实 19 条、明确不满足 0 条；能看到具体解释及资料补充入口。刷新后资格结论仍可见。
- 浏览器点击生成后，现有工作流因没有检索候选，确定性生成 low；0 条匹配、0 条相关证据、0 条硬条件缺口，未冒充挑战岗位。副本新增一份独立 v2 报告，实际快照 providerCalls=0、dbWrites=1；由 Python 响应映射后通过共享 JSON Schema 校验。未写入原库或上一阶段的迁移副本。
- 原始资料、密钥、完整证据不进入文档。日志、私有隔离副本和截图仅存临时目录 `/tmp/joblens-eligibility.5IM6kQ/`。

### 明确未完成的边界

- 正式四组展示、不同页面的历史报告提示、旧材料消费入口统一属于 2C；本轮仅隔离当前批次排序，不能声称所有历史消费者已升级。
- 保存的完整报告尚不能在岗位页刷新后自动重新打开；待阶段 3/4 的结果查询与工作台完成，不能用本轮截图声称已具备完整结果恢复。
- SearchIntent 硬条件尚未接入，下一切片为 2B；总年限解析仍为现有中文表达规则，不声称支持任意约束、复杂区间或例外。
- 无检索候选可确定性返回证据不足；存在候选且确需模型时仍应遵守现有禁用配置，本轮没有调用模型或验收其输出。
