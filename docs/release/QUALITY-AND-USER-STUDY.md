## 2026-11-23 火山方舟联调

用户开通北京区 `doubao-seed-2-0-lite-260428` 并在本机配置密钥后，严格 JSON Schema 连通性验证返回 HTTP 200。另在新建、迁移的隔离 SQLite 库通过真实业务接口验证了四次模型调用：两条已冻结正文和核对项的公开岗位、一次合成简历草稿、一次合成经历语义匹配。没有发送真简历；密钥、原文、逐次回执和隔离库均不进 Git。

自带密钥（BYOK）验收区分三件事：配置的服务是否接受请求、回复是否通过结构与证据校验、结果是否保存且可重开。此前 HTTP 402 和 HTTP 400 是各自的失败记录，不据此推断都是额度问题，也不计为成功请求。

| 样本 | 已核对的结果 |
| --- | --- |
| Apple 数据工程岗位 | 19 条要求有原文依据；7 年保留为优先项、编程语言为三选一、学历保留等效经历选项。核对后通过一次语义调用保存报告；合成 Python 经历只支持有据可查的语言条件，未把单机 Docker 经历当成 Spark 或 Kubernetes 证据，整体为挑战岗位。 |

| 合成开发简历 | 生成 6 条可追溯到原文的草稿，未自动写入正式资料。 |

5 次实际请求均为 HTTP 200（含连通性验证），输入 8,805、输出 7,327 Token。按[方舟常规在线推理公开价](https://docs.volcengine.com/docs/ark/model-pricing?lang=zh)估算 ¥0.0316602，实际账单未核对。四个应用调用各尝试一次，未确认时不发送，同一请求重放不重复发送；56 项相关后端回归通过，SQLite 完整性和外键检查通过。此为本地接口与样本级技术核对，不是浏览器真人试用或完整模型放行；没有覆盖单独的年限硬冲突样本、独立人工标签或远端环境。

## 真实模型：先冻结，再运行

以下是独立标注放行计划，不把上方开发回归和浏览器模拟算成独立评审。

1. 维护者重新确认首次最多 5 元、总计 20 元的执行授权；核对已配置服务、模型、接口类型、余额、人民币换算依据、输入／输出单价。密钥不进入本文件。无法核实价格和余额就停止。
2. 在被 Git 忽略的 `data/evals/private/` 准备五个有权处理的真实岗位；每例包括采集日期、来源、原文摘要哈希、岗位编号、人工要求、硬条件、对应已确认经历编号、期望未知项与人工排序。公开只用脱敏摘要，未获发布权限不上传原文。
3. 五个槽位固定为普通要求／语义近似／年限硬条件／信息缺失／复杂组合；人工标注先于模型结果。冻结数据哈希，首次结果不得被后一次覆盖。
4. 新建独立验收数据库并迁移；不得升级唯一真实库。复用现有岗位提取授权接口、语义调用记录、要求审核和匹配评估，不另写模型链路。
5. 首次仅一个短提取请求。402／401／价格不明／费用不确定即停止，记录状态；不要启动多请求健康探测替代这一步。
6. 每次调用前在台账预留最坏费用：输入上界（包含系统提示、Schema 和实际内容）×输入单价＋输出上限×输出单价；包括推理输出的计费。无法保守估算就不运行。已确认费用＋未决预留不得超过本阶段限额。不确定请求不释放预留、不自动重试。
7. 对同一事实分别保存规则与语义匹配结果。仅允许一轮针对性修正；保留第一次错误、修改原因和复验结果。模型输出不能直接升级职业事实。

## 2026-11-20 本地复验

### 国内平台抓取

真实浏览器操作，经本地正式网页与实际网络校验客户端，不使用模拟网页或模型。[BOSS 直聘测试岗](https://m.zhipin.com/job_detail/55f8cc30b9847b940nxy39W8F1JX.html)与[前端岗](https://m.zhipin.com/job_detail/68ba0fb424aec3e30n1629W7FFNQ.html)均进入验证页，应用停止抓取并提供手动粘贴，焦点移到粘贴框；[牛客已结束岗位](https://www.nowcoder.com/jobs/detail/328085)与[猎聘暂停岗位](https://www.liepin.com/job/1985036191.shtml)都不生成草稿。这些分支保留未保存的手填内容。未尝试绕过验证。

[牛客在招样本](https://www.nowcoder.com/jobs/detail/462580)通过静态提取取得标题、雇主和完整职责与要求；未混入招聘者、推荐或页尾。预览提示确认替换已有草稿，回填后数据库仍为 0 个岗位，手动保存后变为 1 个。五次预览均为 `providerCalls=0`。后端全量 2,051 项（启用 Chromium 集成测试）、前端 386 项、类型检查与正式构建在本地通过。

### 三轮模拟，不计入真人试用

Computer Use 从三个独立演示库开始，三轮均能看到“离线合成演示”、检查三个岗位并比较其中两个、确认 Python 后端岗位并开始准备行动。Python 有已确认经历支持；TypeScript 是证据不足而不是断言不会；高级后端的岗位详情说明已确认 2 年低于要求的 5 年。刷新后，三个库分别保留 1 个准备工作区和 1 项进行中的行动，均无提取或语义调用记录。

| 模拟 | 路径与观察 |

| S1 | 从首页推荐入口开始，首次打开工作区先显示简历，切到「行动」后可开始任务。 |

上述结果只证明路径可用，不证明陌生用户能独立理解，也没有真人计时或旧版真人基线。外部试用仍按 U1–U3 记录。

### 新真实岗位模型：首条请求停止

按新一轮授权，限定北京区 `qwen3.8-flash`、最多 5 次实际请求、总上限 5 元，不发送私人履历。用户已在控制台确认账户与额度，按[北京公开单价](https://help.aliyun.com/zh/model-studio/qwen3-8-flash)做费用上限预留。模型输出前冻结牛客、Apple 中国和 Microsoft 中国三个公开岗位的正文哈希及核对项（在读／出勤未知、优先年限和资格替代、明确年限硬条件），并准备合成经历；没有独立人工标签复核。原文、标签、回执与临时数据库不进 Git。

通过既有的逐次授权提取接口，北京时间 16:16 仅发送牛客样本一次，约 0.48 秒结束，返回 HTTP 400，无可用要求、用量或具体厂商错误码；本轮未做规则与语义的匹配质量对照。实际费用待账单核实，不记零；没有重试或切换模型，另外两个样本没有发送。此结果不是此前 HTTP 402 的重现，也不证明质量通过。下一步先从厂商回执或日志定位明确拒因，并核对费用，再评估是否值得做一次有针对性的复验。
