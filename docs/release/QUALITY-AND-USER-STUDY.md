## 真实模型：先冻结，再运行

1. 维护者重新确认首次最多 5 元、总计 20 元的执行授权；核对已配置服务、模型、接口类型、余额、人民币换算依据、输入／输出单价。密钥不进入本文件。无法核实价格和余额就停止。
2. 在被 Git 忽略的 `data/evals/private/` 准备五个有权处理的真实岗位；每例包括采集日期、来源、原文摘要哈希、岗位编号、人工要求、硬条件、对应已确认经历编号、期望未知项与人工排序。公开只用脱敏摘要，未获发布权限不上传原文。
3. 五个槽位固定为普通要求／语义近似／年限硬条件／信息缺失／复杂组合；人工标注先于模型结果。冻结数据哈希，首次结果不得被后一次覆盖。
4. 新建独立验收数据库并迁移；不得升级唯一真实库。复用现有岗位提取授权接口、语义调用记录、要求审核和匹配评估，不另写模型链路。
5. 首次仅一个短提取请求。402／401／价格不明／费用不确定即停止，记录状态；不要启动多请求健康探测替代这一步。
6. 每次调用前在台账预留最坏费用：输入上界（包含系统提示、Schema 和实际内容）×输入单价＋输出上限×输出单价；包括推理输出的计费。无法保守估算就不运行。已确认费用＋未决预留不得超过本阶段限额。不确定请求不释放预留、不自动重试。
7. 对同一事实分别保存规则与语义匹配结果。仅允许一轮针对性修正；保留第一次错误、修改原因和复验结果。模型输出不能直接升级职业事实。
