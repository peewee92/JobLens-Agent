## 初步检查发现（编码助手，非人工质量验收）

- R1 的任选框架与任选语言保留为组合约束，没有强制要求同时掌握全部语言；但框架／协议细项的检索覆盖还需单独验证。
- R3 保存了两年相关经验和计算机视觉优先项；部署能力存在整句约束与拆分经验重叠，后续应检查是否导致重复计权。
- R4 保留“过去两年内至少三个生产项目”和“技术五年、AI 至少两年”等原文条件；是否在资格判断中正确解析组合，尚未验收。
- R5 没有擅自补全截断文字，但仍返回部分残句作为要求。**接口成功不等于输入质量合格**；本例不得作为“原文完整解析”通过样本，仍需来源质量标记与人工核对。

本轮不修改提示词追求这五例的表面满分；保留第一次结果与失败点，避免对小样本过拟合。

- 排序符合真实用户优先级，或提高录用率。
